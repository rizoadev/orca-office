# Pi Extensions — Global (untuk semua sesi Pi di mesin)

Folder ini berisi **semua Pi extension global** yang dipakai setup ini, termasuk hasil build `pi-office`.

## Isi & peran

| File | Peran | Aktif saat |
|---|---|---|
| `pi-office.ts` | **Extension kantor ORCA24** (hasil build dari `extension/*.ts`) | semua sesi `pi` — auto-skip bila project lokal punya extension sendiri |
| `soul-anchor.ts` | Pertahankan persona `~/.pi/agent/SYSTEM.md` dari injeksi endpoint | setiap request keluar |
| `pi-token-footer.ts` | Footer TUI: token ↑↓, cost, context %, git | semua sesi |
| `orca-agent-status.ts` | Status sesi → Orca (managed by Orca) | pane Orca |
| `orca-prefill.ts` | Prefill editor dari Orca | pane Orca + startup |
| `orca-titlebar-spinner.ts` | Spinner Braille di titlebar | pane Orca |

> **`pi-office.ts` di folder ini adalah GENERATED** (`GENERATED by tools/build-global-extension.js — do not edit here`). Sumber kebenarannya `extension/*.ts` di root repo; file ini adalah salinan hasil build supaya repo membawa artefak yang persis sama dengan yang terpasang global. Rebuild: `npm run sync:extension`.

## Instalasi ke mesin

```bash
cd ~/.pi/office
./scripts/install-extensions.sh all
# = office   : npm run sync:extension → ~/.pi/agent/extensions/pi-office.ts (+ backup)
# + extras   : salin soul-anchor, pi-token-footer, orca-* ke ~/.pi/agent/extensions/
```

## Cara kerja pi-office

Extension Pi yang membuat tiap sesi `pi` terdaftar ke kantor virtual ORCA24 (persona Indonesia, task, tool call, stream LLM, billing). Detail lengkap: [docs/EXTENSIONS.md](../docs/EXTENSIONS.md).
